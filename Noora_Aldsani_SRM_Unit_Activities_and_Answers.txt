UNIT 8 — CONDITIONAL FAULT TREES
Activity: Explain the theme and apply it to Pampered Pets.
Brief answer: Use one minus the product of complements within each assumed condition, then weight normal and stressed conditions. Independence remains an assumption.
Example: For two conditionally independent events with probabilities 0.10 and 0.20, an OR outcome has probability 1-(0.9*0.8)=0.28. An AND outcome has probability 0.10*0.20=0.02. These calculations require the stated independence assumption.

RECALCULATING THE INDIVIDUAL SUMMARY
The following code uses the supplied analyst assumptions. It does not collect empirical data. Copy into a Python 3 file to reproduce the arithmetic.

import math

def union_probability(probabilities):
    if any(p < 0 or p > 1 for p in probabilities):
        raise ValueError("Each probability must be between zero and one")
    return 1 - math.prod(1-p for p in probabilities)

def conditional_result(normal, stress, stress_weight):
    return ((1-stress_weight)*union_probability(normal)
            + stress_weight*union_probability(stress))

quality_normal = [0.010, 0.015, 0.008, 0.005]
quality_stress = [0.050, 0.060, 0.040, 0.030]
supply_normal = [0.060, 0.040, 0.030, 0.020, 0.015]
supply_stress = [0.250, 0.180, 0.120, 0.100, 0.080]
for label, normal, stress in [
    ("Quality per delivered batch", quality_normal, quality_stress),
    ("Supply disruption per month", supply_normal, supply_stress)
]:
    baseline = conditional_result(normal, stress, 0.10)
    improved = conditional_result([p/2 for p in normal],
                                  [p/2 for p in stress], 0.05)
    print(f"{label}: baseline {baseline:.4%}; assumed improvement {improved:.4%}")
    for weight in [0.05, 0.20]:
        print(f"  Stress weight {weight:.2f}: "
              f"{conditional_result(normal, stress, weight):.4%}")
